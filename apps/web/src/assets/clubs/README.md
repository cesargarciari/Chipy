# Club crests (overseas / EuroLeague)

Drop `<clubId>.<ext>` — lower-snake-case ids. Picked up automatically via
`src/lib/art.ts`. Extensions: `.png` `.jpg` `.jpeg` `.webp` `.svg` (any case).
Renders next to club names via `clubCrest(id)`.
