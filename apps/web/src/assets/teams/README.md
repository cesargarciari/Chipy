# Team logos (NBA)

Drop `<TEAMID>.<ext>` — the 3-letter id, **uppercase** (`BOS.png`, `LAL.svg`).
Picked up automatically via `src/lib/art.ts`. Extensions: `.png` `.jpg` `.jpeg`
`.webp` `.svg`. Renders next to team names in the award modal and moment cards.

East — `BOS` `BKN` `NYK` `PHI` `TOR` `CHI` `CLE` `DET` `IND` `MIL` `ATL` `CHA`
`MIA` `ORL` `WAS`
West — `DAL` `DEN` `GSW` `HOU` `LAC` `LAL` `MEM` `MIN` `NOP` `OKC` `PHX` `POR`
`SAC` `SAS` `UTA`

> The **id** part is case-sensitive (`den.png` won't match team `DEN`), but the
> extension can be any case (`DEN.PNG` is fine).
>
> Trademarks belong to their owners — this is a fan project.
